# 📚 Aiobale Examples Directory

مجموعه مثال‌های کاربردی و آماده برای ساخت انواع ربات‌های پیام‌رسان بله:

1. **`01_quickstart.py`**: شروع سریع و پاسخ به دستورات پایه (`/start`, `/help`, `/id`).
2. **`02_fsm_registration.py`**: فرم چندمرحله‌ای ثبت‌نام و استخدام با نگهداری حالت در دیتابیس SQLite.
3. **`03_shop_and_wallet.py`**: کاتالوگ فروشگاهی، صفحه‌بندی هوشمند کالاها و استعلام موجودی کیف‌پول.
4. **`04_group_anti_spam.py`**: ربات مدیریت گروه، ضدلینک و دستورات ادمین (`/ban`, `/kick`).
5. **`05_broadcast_queue.py`**: ارسال پیام همگانی (Broadcast) با کنترل ریت‌لیمیت و نوار پیشرفت زنده.
6. **`06_multi_clients.py`**: اجرای همزمان چندین اکانت و ربات با `ClientManager`.
