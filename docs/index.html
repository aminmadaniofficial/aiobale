    فریم‌ورک مدرن، سریع و رسمی/غیررسمی پیام‌رسان بله

    توسعه سریع و مدرن ربات و کلاینت در پیام‌رسان بله با پایتون

    Aiobale یک کتابخانه پیشرفته، کاملاً ناهمگام (Async/Await) و بر پایه پروتکل بومی وب‌سوکت و باینری پروتوباف پیام‌رسان بله است که امکان ساخت انواع ربات‌های کاربری (Userbot)، ربات‌های رسمی، پنل‌های مدیریت خودکار و ابزارهای داده‌کاوی را با بالاترین سرعت و کمترین مصرف منابع فراهم می‌کند.

    شروع سریع مشاهده متدهای API

    کاملاً Async/Await

    طراحی‌شده بر پایه asyncio پایتون با توان پردازش همزمان هزاران رویداد در ثانیه با حداقل مصرف رم و پردازنده.

    مجیک فیلتر هوشمند (F)

    فیلترگذاری شبیه به Aiogram با عبارت‌های قدرتمند F.text.startswith(...) و فیلترهای ترکیبی منطقی.

    پوشش ۷۹+ متد RPC

    دسترسی به تمام قابلیت‌های پیام‌رسان بله شامل پیام‌ها، گروه‌ها، کانال‌ها، ری‌اکشن‌ها، فایل‌ها و استاتوس.

    مدل‌های داده Pydantic

    اعتبارسنجی خودکار داده‌ها با تایپ هینتینگ ۱۰۰٪ سازگار با تمامی IDEها نظیر VS Code و PyCharm.

    نصب و پیش‌نیازها (Installation)

    راهنمای راه‌اندازی و نصب کتابخانه Aiobale روی سیستم‌عامل‌های مختلف

    برای استفاده از Aiobale، به پایتون نسخه 3.8 یا بالاتر (سازگار تا پایتون 3.14) نیاز دارید.

    نصب با pip

    Terminal 
    # نصب مستقیم از سورس یا پکیج
pip install aiobale

# یا نصب با ابزار سریع uv
uv pip install aiobale
    نکته توسعه در لینوکس / داکر: وابستگی‌های اصلی نظیر aiohttp، pydantic، blackboxprotobuf و aiofiles به صورت خودکار نصب می‌شوند.

    اولین ربات در ۵ دقیقه (Quickstart)

    ساخت یک ربات اکو (Echo Bot) هوشمند در پیام‌رسان بله

    نمونه کد زیر یک ربات اکو ساده ایجاد می‌کند که به تمام پیام‌های متنی دریافتی پاسخ همان پیام را می‌دهد:

    main.py 
    import asyncio
from aiobale import Client, Dispatcher, F
from aiobale.types import Message
from aiobale.filters import IsText

# ساخت دیسپچر و کلاینت
dp = Dispatcher()
client = Client(dp, session_file="my_bot")

@dp.message(F.text == "/start")
async def start_handler(message: Message):
    await message.reply("سلام! به ربات Aiobale خوش آمدید.")

@dp.message(IsText())
async def echo_handler(message: Message):
    await message.reply(f"شما گفتید: {message.text}")

async def main():
    print("در حال اتصال به سرور بله...")
    await client.start()

if __name__ == "__main__":
    asyncio.run(main())

    در اولین اجرای این اسکریپت در ترمینال، کنسول از شما شماره تلفن و کد پیامک‌شده را می‌پرسد و سشن ذخیره می‌شود تا در اجراهای بعدی بدون نیاز به لاگین مجدد متصل شود.

    احراز هویت و مدیریت سشن (Authentication)

    راهنمای انواع روش‌های لاگین، کار با توکن‌ها و فایل‌های سشن

    ۱. ورود با شماره تلفن و CLI

    می‌توانید شماره تلفن را مستقیماً در کد پاس دهید تا فقط کد تایید پیامک‌شده در ترمینال پرسیده شود، یا بدون شماره فراخوانی کنید تا ورود کامل تعاملی باشد:

    auth_phone.py 
    from aiobale import Client

# ۱. پاس دادن مستقیم شماره در کد (پرسش فقط برای کد تایید پیامکی)
client = Client(session_file="my_account", phone_number="09123456789")

# ۲. یا لاگین تعاملی کامل با پرسش شماره و کد در ترمینال
# client = Client(session_file="my_account")

if __name__ == "__main__":
    client.run()

    ۲. ورود با توکن JWT از پیش موجود

    در صورتی که توکن حساب کاربری را دارید، می‌توانید آن را به صورت مستقیم به کلاینت پاس دهید:

    token_auth.py 
    from aiobale import Client

MY_JWT_TOKEN = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# راه‌اندازی با توکن مستقیم بدون نیاز به فایل سشن روی دیسک
client = Client(session_file=None, token=MY_JWT_TOKEN)

    ۳. محیط‌های Headless و داکر (Docker & CI)

    در صورتی که برنامه در محیط بدون ورودی ترمینال اجرا شود (مانند Docker یا دیمون‌های پس‌زمینه)، در صورت نبود توکن خطای واضح AiobaleError پرتاب می‌شود تا از فریز شدن پروسس جلوگیری شود.

    معماری کلاینت و چرخه حیات (Client Architecture)

    بررسی کلاس Client، تنظیمات اتصال، پراپرتی‌ها و هندلینگ قطعی اتصال

    پارامترهای کانفیگوریشن کلاینت

    پارامتر نوع داده (Type) پیش‌فرض توضیحات
    dispatcher Optional[Dispatcher] None آبجکت دیسپچر مسئول مدیریت و هدایت رویدادها
    session_file Union[str, Path, bytes, None] "./session.bale" مسیر فایل ذخیره‌سازی نشست یا None برای نشست حافظه‌ای
    token Optional[str] None توکن JWT معتبر جهت اتصال مستقیم
    user_agent Optional[str] None عنوان کلاینت یا User-Agent اختصاصی
    show_update_errors bool False نمایش خطاهای رخ‌داده در جریان پردازش آپدیت‌ها در لاگ

    چرخه حیات و متدهای کلاینت

    متد / پراپرتی نوع توضیحات
    client.start() async برقراری اتصال سوکت، لاگین، دریافت اطلاعات اکانت و آغاز حلقه آپدیت‌ها
    client.stop() async قطع ایمن سوکت، ذخیره وضعیت و توقف کلاینت
    client.me پراپرتی آبجکت اطلاعات حساب لاگین‌شده (شامل نام، آیدی، شماره تلفن و...)
    client.id پراپرتی آیدی عددی کاربر متصل‌شده (در صورت عدم اتصال مقدار None)
    client.token پراپرتی توکن JWT فعال برای درخواست‌های HTTP و آپلود/دانلود مدیا

    دیسپچر و مسیریابی رویدادها (Dispatcher & Routers)

    سیستم قدرتمند هدایت و دریافت رویدادها با قابلیت ماژولار و تزریق وابستگی

    انواع رویدادهای پشتیبانی‌شده در دیسپچر

    دکوراتور هندلر نوع ورودی (Event Object) زمان تحریک (Trigger)
    @dp.message(*filters) Message دریافت پیام جدید در پیوی، گروه یا کانال
    @dp.message_edited(*filters) Message ویرایش شدن متن یا کپشن پیام ارسالی قبلی
    @dp.message_deleted(*filters) SelectedMessages حذف شدن یک یا چند پیام
    @dp.user_blocked(*filters) UserBlocked بلاک شدن کاربر توسط شما یا طرف مقابل
    @dp.user_unblocked(*filters) UserUnblocked آنبلاک شدن کاربر
    @dp.group_message_pinned(*filters) PinnedMessage پین شدن پیام جدید در گروه یا کانال
    @dp.group_pin_removed(*filters) UnpinnedMessage حذف پیام پین‌شده از سرگروه
    @dp.username_changed(*filters) UsernameChanged تغییر نام کاربری (آیدی @) گروه یا کانال
    @dp.about_changed(*filters) AboutChanged تغییر بیوگرافی یا توضیحات گروه/کانال

    ساختار پروژه‌های بزرگ با Router

    برای تفکیک کدهای بات در فایل‌های مجزا (مثلاً هندلرهای ادمین، هندلرهای کاربری، هندلرهای مدیا)، از روترها استفاده کنید:

    handlers/admin.py 
    from aiobale import Router, F
from aiobale.types import Message

admin_router = Router()

@admin_router.message(F.text == "/panel")
async def admin_panel(msg: Message):
    await msg.reply("به پنل مدیریت خوش آمدید.")
    bot.py 
    from aiobale import Client, Dispatcher
from handlers.admin import admin_router

dp = Dispatcher()
# الحاق روتر ادمین به دیسپچر اصلی
dp.include_router(admin_router)

client = Client(dp, session_file="bot")

    تزریق وابستگی خودکار (Dependency Injection)

    در هر هندلر می‌توانید علاوه بر آبجکت رویداد (مثلاً msg: Message)، آبجکت client: Client یا هر متغیر دلخواه تزریق‌شده را به عنوان آرگومان تعریف کنید تا سیستم آن را به صورت خودکار مقداردهی کند.

    فیلترها و Magic Filter (Filters & F)

    کنترل دقیق و گزینش هوشمند رویدادها با فیلترهای جادویی و منطقی

    استفاده از Magic Filter (`F`)

    با آبجکت F می‌توانید بدون نیاز به نوشتن توابع جداگانه، شرط‌های پیچیده را مستقیماً تعریف کنید:

    magic_filters.py 
    from aiobale import F
from aiobale.enums import ChatType

# تطابق دقیق متن
@dp.message(F.text == "ping")
async def on_ping(msg): await msg.reply("pong")

# شروع با پیشوند خاص
@dp.message(F.text.startswith("/calc"))
async def on_calc(msg): ...

# شرط روی نوع چت و فرستنده
@dp.message(F.chat.type == ChatType.GROUP, F.sender_id == 123456)
async def on_admin_in_group(msg): ...

# بررسی وجود سند یا تصویر
@dp.message(F.content.document)
async def on_document(msg): ...

    فیلترهای پیش‌ساخته (Built-in Filters)

    فیلتر عملکرد
    IsText() فقط پیام‌های متنی عادی
    IsDocument() پیام‌های حاوی فایل یا مدیا
    IsGift() پیام‌های بسته هدیه / عیدی بله
    IsPrivate() پیام‌های دریافتی از چت‌های دونفره (پیوی)
    IsGroupOrChannel() پیام‌های گروه‌ها، ابرگروه‌ها یا کانال‌ها
    ChatTypeFilter(ChatType.GROUP) فیلتر بر اساس نوع اختصاصی چت
    RegexFilter(r"^/ban\s+(\d+)") استخراج و انطباق عبارات منظم (RegEx)

    ترکیب منطقی فیلترها (Logic Operators)

    با توابع and_f, or_f, invert_f می‌توانید فیلترها را ترکیب کنید:

    logic_filter.py 
    from aiobale.filters import and_f, or_f, invert_f, IsText, IsPrivate

# پیام متنی باشد و در پیوی باشد
@dp.message(and_f(IsText(), IsPrivate()))
async def private_text_only(msg): ...

# پیام غیرمتنی باشد (معکوس کردن)
@dp.message(invert_f(IsText()))
async def media_only(msg): ...

    ساخت فیلتر سفارشی (Custom Filter)

    custom_filter.py 
    from aiobale.filters.base import Filter
from aiobale.types import Message

class AdminOnly(Filter):
    def __init__(self, admin_ids: list[int]):
        self.admin_ids = admin_ids

    async def __call__(self, message: Message) -> bool:
        return message.sender_id in self.admin_ids

@dp.message(AdminOnly([111222, 333444]))
async def admin_handler(msg: Message):
    await msg.reply("دسترسی ادمین تایید شد.")

    ماشین وضعیت و میدلورها (FSM & Middlewares)

    مدیریت گفتگوهای چندمرحله‌ای، فرم‌ها، سبد خرید و پایپ‌لاین رهگیری پیام‌ها

    ۱. تعریف مراحل با StatesGroup و FSMContext

    با ارث‌بری از StatesGroup وضعیت‌های گفتگو را تعریف کنید و در هندلرها با state: FSMContext داده‌ها را ذخیره و فراخوانی نمایید:

    fsm_form.py 
    from aiobale import Client, Dispatcher, F
from aiobale.fsm import State, StatesGroup, FSMContext
from aiobale.types import Message

class OrderForm(StatesGroup):
    choosing_item = State()
    choosing_quantity = State()

dp = Dispatcher()

@dp.message(F.text == "/order")
async def start_order(msg: Message, state: FSMContext):
    await state.set_state(OrderForm.choosing_item)
    await msg.reply("نام محصول را وارد کنید:")

@dp.message(OrderForm.choosing_item)
async def item_chosen(msg: Message, state: FSMContext):
    await state.update_data(item_name=msg.text)
    await state.set_state(OrderForm.choosing_quantity)
    await msg.reply("تعداد مورد نظر را وارد کنید:")

@dp.message(OrderForm.choosing_quantity)
async def quantity_chosen(msg: Message, state: FSMContext):
    data = await state.get_data()
    item = data.get("item_name")
    await state.clear()
    await msg.reply(f"سفارش شما برای {msg.text} عدد {item} ثبت شد!")

    ۲. استوریج‌های پایدار: SQLiteStorage

    به طور پیش‌فرض داده‌های FSM در رم ذخیره می‌شوند. برای جلوگیری از پاک شدن وضعیت کاربران هنگام ری‌استارت، از SQLiteStorage استفاده کنید:

    persistent_storage.py 
    from aiobale import Dispatcher, SQLiteStorage

# ذخیره دائمی وضعیت‌ها در دیتابیس SQLite
storage = SQLiteStorage("fsm_data.db")
dp = Dispatcher(storage=storage)

    ۳. پایپ‌لاین میدلورها (BaseMiddleware)

    برای کنترل نرخ درخواست‌ها (Rate Limiting)، آمارگیری، احراز هویت و لاگینگ قبل از اجرای هر هندلر:

    custom_middleware.py 
    from aiobale import Dispatcher, BaseMiddleware
from typing import Any, Callable, Dict, Awaitable

class LoggingMiddleware(BaseMiddleware):
    async def __call__(
        self,
        handler: Callable[[Any, Dict[str, Any]], Awaitable[Any]],
        event: Any,
        data: Dict[str, Any]
    ) -> Any:
        print(f"دریافت رویداد: {event}")
        result = await handler(event, data)
        print("پردازش هندلر به اتمام رسید.")
        return result

dp = Dispatcher()
dp.middleware(LoggingMiddleware())

    کیبورد سازها، پارسر دستورات، کال‌بک فکتوری و اجرای همزمان چنداکانت

    ۱. کیبورد سازهای زنجیره‌ای (Keyboard Builders)

    ساخت سریع کیبوردهای شیشه‌ای و معمولی با متدهای متوالی و چینش ماتریسی دلخواه:

    keyboards_demo.py 
    from aiobale.utils.keyboard import InlineKeyboardBuilder, ReplyKeyboardBuilder

# کیبورد شیشه‌ای (Inline)
builder = InlineKeyboardBuilder()
builder.button(text="🌐 وبسایت رسمی", url="https://aiobale.ir")
builder.button(text="دکمه ۱", callback_data="cb_1")
builder.button(text="دکمه ۲", callback_data="cb_2")
inline_kb = builder.as_markup(2, 1)  # سطر اول ۲ تا، سطر دوم ۱ دکمه

# کیبورد معمولی (Reply)
reply = ReplyKeyboardBuilder()
reply.button(text="👤 پروفایل کاربری")
reply.button(text="🛍️ فروشگاه")
reply_kb = reply.as_markup(2)

    ۲. فیلتر پیشرفته دستورات (Command Filter & CommandObject)

    پارس خودکار نام دستور، پیشوند (مانند / یا !) و آرگومان‌های ارسالی با تزریق به هندلر:

    commands_demo.py 
    from aiobale import Command, CommandObject
from aiobale.types import Message

@dp.message(Command("ban", "kick", prefix="/!"))
async def admin_command(msg: Message, command: CommandObject):
    print(command.prefix)     # پیشوند استفاده شده مثلا '!'
    print(command.command)    # نام دستور مثلا 'ban'
    print(command.args)       # رشته کامل آرگومان‌ها
    print(command.args_list)  # لیست آرگومان‌ها به صورت تک‌تک
    await msg.reply(f"دستور {command.command} دریافت شد.")

    ۳. کال‌بک فکتوری با مدل‌های تایپ‌شده (CallbackData)

    تعریف ساختار داده‌ای تمیز برای دکمه‌ها و فیلترگذاری بدون پردازش دستی رشته‌ها:

    callback_factory.py 
    from aiobale import CallbackData, F

class ProductCB(CallbackData, prefix="product"):
    action: str
    product_id: int

# تولید دیتای دکمه: product:view:99
data_str = ProductCB(action="view", product_id=99).pack()

@dp.message(ProductCB.filter(F.action == "view"))
async def on_view_product(event, callback_data: ProductCB):
    print(f"شناسه محصول: {callback_data.product_id}")

    ۴. مدیریت و اجرای همزمان چنداکانت (ClientManager)

    مرجع متدهای پیام‌رسانی (Messaging API)

    ارسال انواع پیام، تصویر، فایل، ویرایش، حذف، پین و تاریخچه چت

    نام متد نوع پارامترهای اصلی توضیحات
    send_message async chat_id, text, reply_to, quoted_message ارسال پیام متنی با پشتیبانی از ریپلای نقل‌قولی
    send_photo / send_document async chat_id, file, caption, reply_to ارسال تصویر یا فایل از مسیر دیسک یا باینری
    send_voice / send_video async chat_id, file, duration, caption ارسال ویس یا ویدیوی پلیر با پیش‌نمایش
    update_message async chat_id, message_id, text ویرایش متن پیام ارسال‌شده قبلی
    delete_message async chat_id, message_ids حذف یک یا چند پیام برای طرفین
    forward_message async from_chat_id, to_chat_id, message_ids فوروارد پیام‌ها به چت دیگر
    load_history async chat_id, limit, offset_id دریافت لیست تاریخچه پیام‌های چت
    load_dialogs async limit, offset_date دریافت لیست گفتگوها و چت‌های فعال کاربر
    clear_chat / delete_chat async chat_id پاکسازی یا حذف کامل گفتگوی یک چت

    استعلام موجودی کیف‌پول، شماره حساب و کارت، ارسال بسته هدیه (عیدی) و باز کردن پاکت پول

    متد پارامترها توضیحات و کاربرد
    get_wallet() - دریافت موجودی ریالی، شماره حساب، شماره کارت (PAN) و توکن کیف‌پول کاربر

async def send_gift_pack(msg):

        gift_count=5,
        giving_type=GivingType.RANDOM

    پروژه ۲: ربات ضدلینک و مدیریت گروه (Group Moderation)

    anti_spam_bot.py 
    import re
from aiobale import Client, Dispatcher, F
from aiobale.types import Message
from aiobale.enums import ChatType

dp = Dispatcher()
client = Client(dp, session_file="mod_bot")

LINK_PATTERN = re.compile(r"(https?://|ble\.ir/|t\.me/|eitaa\.com/)")

# حذف پیام‌های حاوی لینک تبلیغاتی در گروه‌ها
@dp.message(F.chat.type == ChatType.GROUP)
async def anti_link_guard(msg: Message, client: Client):
    if msg.text and LINK_PATTERN.search(msg.text):
        # حذف پیام متخلف
        await msg.delete()
        print(f"پیام حاوی لینک از کاربر {msg.sender_id} حذف شد.")

@dp.message(F.text.startswith("/ban"), F.chat.type == ChatType.GROUP)
async def ban_command(msg: Message, client: Client):
    if msg.replied_to:
        target_user = msg.replied_to.sender_id
        await client.kick_user(msg.chat.id, target_user)
        await msg.answer(f"کاربر {target_user} از گروه اخراج شد.")

if __name__ == "__main__":
    client.run()

    پروژه ۴: ربات برودکست و ارسال به کانال (Broadcaster)

    import asyncio
from aiobale import Client

CHANNELS = [100001, 100002, 100003]

async def broadcast_news(text: str):
    client = Client(session_file="sender")
    await client.start()

    for ch_id in CHANNELS:
        try:
            await client.send_message(chat_id=ch_id, text=text)
            print(f"پیام با موفقیت به {ch_id} ارسال شد.")

        except Exception as e:
            print(f"خطا در ارسال به {ch_id}: {e}")

    await client.stop()

if __name__ == "__main__":
    asyncio.run(broadcast_news("اطلاعیه رسمی جدید در کانال‌ها منتشر شد."))

    مدیریت خطاها و عیب‌یابی (Troubleshooting)

    راهنمای جامع رفع خطاهای متداول شبکه، سشن و توکن

    خطا (Error / Exception) علت وقوع راهکار رفع
    AuthErrors.NUMBER_BANNED شماره واردشده در سیستم بله مسدود یا بن شده است با پشتیبانی بله تماس بگیرید یا از شماره دیگری استفاده نمایید
    AuthErrors.RATE_LIMIT درخواست‌های لاگین مکرر در بازه کوتاه چند دقیقه صبر کرده و مجدداً اقدام فرمایید
    AiobaleError: Authentication token is required... اجرا در داکر یا محیط Headless بدون ارسال توکن پارامتر token="..." را مستقیماً به Client پاس دهید
    ConnectionResetError / Socket Closed قطعی موقت اینترنت یا اتصال شبکه کلاینت به صورت پیش‌فرض تلاش مجدد خودکار (Auto Reconnect) را انجام می‌دهد
    توسعه داده شده با دقت و کیفیت برای اکوسیستم متن‌باز پیام‌رسان بله.
